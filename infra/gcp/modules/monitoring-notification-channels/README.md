Provide `GCP_MONITORING_PRIMARY_EMAIL` and `GCP_MONITORING_PRIMARY_EMAIL_CHANNEL` only as private secrets in both development plan/apply Environments. The caller maps only these explicit inputs, masks full values and fragments before authentication, and maintains ordinary development channel ownership after the separately approved `email-adoption` mode completed with post-plan no-op5. The import ID must belong to the development project. No mailbox or deployed channel ID belongs in source, Issue, public logs, Summary or artifacts. `sensitive` propagates through the channel label, module output and quota input; it is not encryption. Email labels can be persisted in the encrypted, access-restricted S3 state.
