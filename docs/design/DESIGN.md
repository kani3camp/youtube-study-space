# オンライン作業部屋 DESIGN.md

この文書は、オンライン作業部屋の広報・SNS告知・YouTubeサムネイル・使い方案内・説明画像などを制作するときのデザイン指針です。

配信画面そのものの実装仕様ではありません。既存の配信UI・ドキュメントサイト・ロゴ・座席表現から抽出した **広報用デザインシステム** として扱います。

## この文書の読み方

この文書には、現在のコードから確認できる **実装事実** と、広報制作で採用する **制作方針** の両方を含みます。

- **実装事実**: コード・設定が正です。値や優先順位を変えた場合はこの文書も追従させます。
- **制作方針**: 広報物を一貫させるための編集・表現ルールです。配信UIの仕様を拘束しません。
- 媒体仕様は変わり得るため、下記の寸法は「本プロジェクトの制作テンプレート既定値」として扱い、公開時に媒体側の要件も確認します。

### 実装事実の主な参照元

## 目的

広報物に、一貫した見た目・雰囲気・言葉づかいを持たせます。特にAI画像生成、Canva/Figma制作、SNS投稿画像、YouTubeサムネイル作成時に毎回デザインの方向性がぶれないことを目的にします。

## ブランドの基本方針

オンライン作業部屋は、YouTubeライブ上の作業・勉強・読書・休憩のためのオンライン空間です。広報では次の価値を中心に表現します。

- 静かに作業できる
- 出入り自由で参加しやすい
- カメラ・マイク不要で気軽
- 勉強・仕事・読書・創作・休憩などに使える
- 作業時間が少しずつ積み上がる
- ひとりだけど、ひとりではない感覚がある
- 長く見ても疲れにくい

## 累計時間カラー

累計時間カラーは、サービス固有の「継続が可視化される」要素です。広報デザイン全体の主役にはせず、細いバー、座席カードの上辺、小さなスウォッチなどに限定します。

### 実装上の座席色の優先順位

機能説明画像で実際の座席色を再現する場合、累計時間カラーが常に表示されるわけではありません。`system/core/utils/seat_appearance.go` の `GetSeatAppearance` では次の順で決まります。

1. `rankVisible == true` の場合はランク/RP由来のグラデーションが優先される。
2. ランク表示でなく、累計1000時間以上かつ好きな色が設定されている場合は好きな色が優先される。
3. それ以外の場合に累計時間カラー15段階を使う。

広報上の抽象表現として累計時間カラーバーを使うことは問題ありませんが、実画面の再現画像ではこの優先順位を守ります。

## カラールール

### OK

- 見出しに `#3A1E86` を使う
- CTAボタンに `#8A2BE2` を使う
- ロゴ風アイコンや装飾に `#9153CB` を使う
- カード背景に `#F4EFE7` を使う
- 情報カードの補助文字に `#5A5146` を使う
- 作業名や重要情報に `#24317E` を使う
- 累計時間カラーは細いラインや小さなスウォッチとして使う

### NG

- 全体をグリーン基調にする
- 黒背景にネオン紫を強く当てる
- 累計時間カラーを大面積で敷く
- 赤をメインカラーとして使う
- ランキング感・競争感を強く出す
- 背景を派手にしすぎて文字が読みにくくなる

## タイポグラフィ

読みやすい日本語ゴシックを使います。丸すぎず硬すぎず、画面上で判読しやすいことを優先します。

### 推奨書体と代替順

1. Noto Sans JP
2. BIZ UDPGothic
3. M PLUS 1p
4. Zen Kaku Gothic New
5. M PLUS Rounded 1c

丸みを強く出したい特別なカードだけ `M PLUS Rounded 1c` を優先して構いませんが、本文全体を幼い印象にしないことを優先します。

画像生成時の指定例:

> clean modern Japanese sans-serif, readable, rounded but not childish

### 文字階層

| 階層 | 用途 | 太さ | 例 |
| --- | --- | --- | --- |
| H1 | サムネイル主見出し | Bold / ExtraBold | 一緒に集中しよう。 |
| H2 | 告知タイトル | Bold | 本日も配信中 |
| H3 | セクション見出し | Semibold | 参加方法 |
| Body | 説明文 | Regular / Medium | 出入り自由。カメラ・マイク不要。 |
| Numeric | 時間・人数 | Medium / Bold | 1h 24m / 1000h+ |

### 表記ルール

- 時間表記は `1h 24m` のように小文字 `h` / `m`
- 1000時間以上の訴求は `1000h+`
- 人数は `120人が参加中` のような自然な日本語
- 開始時刻は `21:00〜`
- 感嘆符を多用しない
- 「絶対」「本気」「ガチ」「勝つ」など圧の強い表現を避ける

## 制作条件

### 制作テンプレート既定値

| 用途 | 既定キャンバス | セーフマージン | 文字量の目安 | 縮小確認 |
| --- | --- | --- | --- | --- |
| YouTubeサムネイル | 1280×720 (16:9) | 外周48px以上 | 主見出し1つ + 補助2〜4要素 | 幅320px程度でも主見出しとLIVE/参加要素を判読できる |
| SNS横長告知 | 1200×675 (16:9) | 外周48px以上 | 見出し + 3要点まで | 幅360px程度で本文を読める |
| SNS正方形 | 1080×1080 | 外周64px以上 | 見出し + 3要点まで | 幅360px程度で主要情報を判読できる |
| 縦型告知/ストーリー | 1080×1920 | 外周72px以上。上下に主要情報を詰めすぎない | 1画面1メッセージを優先 | 幅360px相当で見出し・CTAを判読できる |

これらは媒体の最大/必須仕様ではなく、制作物の再現性を上げるためのプロジェクト既定値です。

### 共通レイアウトルール

- 余白を広めに取る
- 情報階層は3段階まで
- 角丸を統一
- 装飾は控えめ
- 文字の上に複雑な背景を置かない
- 一目で何の告知か分かる
- 完成時は必ず縮小表示でも判読性を確認する

広報物では、オンライン作業部屋らしさを伝えるために、座席カード風のUIを積極的に使います。

### 基本構成

```text
┌──────────────────────────────┐
│  12      Jun      読書        │
│  1h 24m              残り36m │
└──────────────────────────────┘
```

### 表示項目

| 項目 | 例 | 色 |
| --- | --- | --- |
| 席番号 | 12 | `#5A5146` |
| 名前 | Jun | `#4A4338` |
| 作業内容 | 読書 | `#24317E` |
| 経過時間 | 1h 24m | `#3A1E86` |
| 残り時間 | 残り36m | `#4A4338` |

### 座席カードのルール

- 背景は `#F4EFE7` を基本にする
- 上辺に細いアクセントラインを入れてよい
- 累計時間カラーは上辺ラインや小さな点で使う
- 情報量を詰め込みすぎない
- 名前より作業内容が目に入りやすいようにする
- 席番号は必ず視認できる位置に置く
- 実画面の座席色を説明する画像では「実装上の座席色の優先順位」を適用する

## レイアウト

### 共通ルール

- 余白を広めに取る
- 情報階層は3段階までにする
- 角丸を統一する
- 装飾は控えめにする
- 背景の情報量を増やしすぎない
- 文字の上に複雑な背景を置かない
- 一目で「何の告知か」が分かるようにする
- 完成時は必ず縮小表示でも主要情報の判読性を確認する

### YouTubeサムネイル

推奨構成:

```text
左: 大きな見出し
右: 作業部屋イラスト or 座席カード風UI
下: LIVE / 出入り自由 / カメラ不要 / 作業記録
```

見出し例:

- 一緒に集中しよう。
- 静かに作業する場所。
- 今日も、作業部屋にいます。
- ひとりだけど、ひとりじゃない作業時間。
- 勉強・作業・読書に、ゆるく参加。

避ける見出し:

- 絶対集中！
- サボるな！
- 勝ち組の作業部屋
- ガチ勢専用
- 限界まで頑張れ

### SNS告知

推奨構成:

```text
上: オンライン作業部屋 ロゴ/名前
中: 今日の配信告知
下: 参加メリット3点
右下: 小さな座席カード or 時計
```

文言例:

```text
本日もオンライン作業部屋を開いています。

出入り自由。
カメラ・マイク不要。
作業や勉強の記録にも。

静かに作業したい時間にどうぞ。
```

### 使い方案内

初見向けには、3ステップに絞ります。

```text
1. YouTubeライブを開く
2. チャットで !in 作業名
3. 席に座って作業開始
```

説明は短くし、コマンド詳細は別ページへ逃がします。
