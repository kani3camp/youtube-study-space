# MyPage visual reference and acceptance

Phase 1のデザイン方針は[Notion 01｜画面・機能仕様](https://app.notion.com/p/3ec357a8d0ce81e293d1d4cb739d3063)、現在の表示は[Reactコンポーネント](../../../mypage/src/features/mypage/view.tsx)と[スタイルシート](../../../mypage/src/style.css)を参照する。デザインの承認は、公開文面・実認証・一般公開の承認とは別に扱う。

## 表示の原則

- クリーム色の背景に淡い光のグラデーションを重ね、明るい面・薄い境界線・静的で柔らかな影を使う。影は作業中なら暖色、休憩中ならセージ系とし、常時アニメーションは加えない。
- 現在の作業を主役にし、作業中は暖色、休憩中はセージ色で区別する。状態を色だけで伝えない。
- 休憩中も通常の`workName`を保持し、「いまの作業」「休憩開始」「休憩終了予定」を表示する。
- 未入室・未登録・正常な0・不明・取得障害を区別する。不完全な履歴の記録済み分は確定合計と混同させない。
- Accountはヘッダーから開き、モバイルではボトムシート、広い画面ではポップオーバーとして表示する。
- キーボードフォーカス、モーダル内のフォーカス循環と背景のinert、Escape、呼び出し元へのフォーカス復帰、status/alert、reduced motion、約44pxの操作対象を維持する。
- 自己配信フォントの由来・ライセンス・描画テーブル・再現方法は[フォントREADME](../../../mypage/src/assets/fonts/README.md)を参照する。

## 視覚・操作確認

代表幅は320 / 390 / 768 / 1024 / 1440pxとする。これらは確認時の観測点であり、CSSブレークポイントの固定値ではない。

- 作業中・休憩中・未入室・未登録・0時間・長い作業名・終了予定超過。
- 初回読み込み、初回取得失敗、部分障害、更新失敗時の直前成功データの保持。
- YouTubeログイン、チャンネル確認、期限切れや競合からのやり直し。
- Accountの開閉・管理・ログアウト、画像欠落時の代替表示。
- Privacy / Terms / Cookie / Contact、利用制限、削除処理中。
- 直近7日のフォーカス・タップによる選択、正常な0分の選択、グラフ外の説明、時刻ラベルの収まり。

表示単体は[表示確認用の入口](../../../mypage/src/visual.tsx)で確認する。認証・ルートを含む状態遷移は[ランタイムテスト](../../../mypage/src/runtime.test.ts)で検証する。表示確認用の入口は開発専用とし、本番の入口に含めない。

```sh
cd mypage
pnpm dev --host 127.0.0.1
# 別shell、Playwright/Chromiumを利用できる環境
python -m pip install -r visual-requirements.txt
pnpm test
python scripts/font-qa.py --output /tmp/mypage-font-qa
python scripts/route-focus-qa.py
```

外部リクエストを遮断し、撮影前にフォントの読み込みを待つ。実ユーザーデータを公開成果物に保存しない。合成テストデータの成功やプロトタイプとの比較を、実OAuth・Hosting・公開準備完了の証拠にしない。

`route-focus-qa.py` は公開ルートのフッターをキーボードで遷移し、本文見出しへのフォーカス、本文内のTab順、戻る・進む、初回表示、Cookie設定を閉じた際のフォーカス復帰をデスクトップ・モバイルで検証する。ルート変更時は描画後の本文見出し（見出しがなければ`main`）へフォーカスを移し、同一ルートの検索条件・アンカー変更では移さない。アンカー付きの遷移は既存のアンカー動作を優先する。

## bfcache・利用制限の確認

旧セッションの遅延応答、復帰時の再検証、制限後にデータが復活しないことは、[ランタイムテスト](../../../mypage/src/runtime.test.ts)と[個人データのメモリテスト](../../../mypage/src/features/mypage/memory.test.ts)の代表ケースで検証する。

実Hosting / Chromiumのbfcache復帰、利用制限中・削除中の320 / 390 / 1440px表示、問い合わせ・新たなログイン・ログアウトは[実経路E2E](../release/e2e.md)で確認する。HMRを実bfcacheの証拠にせず、拒否後の自動再試行と旧データの復活を認めない。

## 仕様の優先順位

文言・本人確認・スナップショット時刻・状態・集計は、最新のAPI仕様を優先する。背景・色・影は上記の表示原則に従う。提供されたプロトタイプと付属ランタイムは公開リポジトリに追加しない。サンプル値や時刻の差を、ピクセル単位の不一致の根拠にしない。
