# MyPage 画面表示のリファレンスと確認手順

Phase 1 のデザイン方針は [Notion 01｜画面・機能仕様](https://app.notion.com/p/3ec357a8d0ce81e293d1d4cb739d3063)、現在の実装は [view.tsx](../../../mypage/src/features/mypage/view.tsx) と [style.css](../../../mypage/src/style.css) を参照してください。なお、デザイン・表示の確認は公開文面の承認や実認証・一般公開の承認とは分けて扱います。

---

## 表示の基本原則

- **配色と質感**: クリーム色の背景に淡い光のグラデーションを重ね、明るい面・薄い境界線・静的で柔らかな影を用います（影は作業中が暖色、休憩中がセージ系。常時アニメーションは付けません）。
- **主役と状態表現**: 「現在の作業」を主役にし、作業中は暖色、休憩中はセージ色で区別します（色だけでなくテキストでも状態を伝えます）。休憩中も `workName` を保持し、「いまの作業」「休憩開始」「休憩終了予定」を表示します。
- **状態の明確な区別**: 「未入室」「未登録」「正常な 0 分」「取得障害」を区別し、集計できない日には理由を表示します。
- **直近 7 日グラフ**: 0 分の日もフォーカス・選択できるよう高さ `3px` のバーを表示します。1 分以上のバーは `5px` を基準に、残りの高さを表示分数に応じて配分します。
- **時刻表示（すべて日本時間 JST）**:
  - 入室状況の基準時刻は「現在の作業」カードの「入室状況」に表示し、作業中・休憩中は開始・終了予定時刻と取得時点の位置を示す点の下に配置します。
  - 今日・今週・累計・直近 7 日の共通基準時刻は作業サマリー下部に「作業集計（直近 7 日を含む）」として表示します。更新失敗で古い値を保持している項目は、共通時刻より古い場合に項目側で元の基準時刻を示します。
- **ナビゲーションとアクセシビリティ**: Account メニューはヘッダーから開き、モバイルではボトムシート、広い画面ではポップオーバーとして表示します。キーボードフォーカス、モーダル内のフォーカス循環と背景 `inert`、`Escape` キー、呼び出し元へのフォーカス復帰、`status`/`alert` ロール、`reduced motion`、約 `44px` の操作領域を維持します。
- **フォント**: 自己配信フォントの由来・ライセンス・補正手順は [フォント README](../../../mypage/src/assets/fonts/README.md) を参照してください。

## 視覚・操作の確認（ローカル合成 QA）

代表確認幅は **320 / 390 / 768 / 1024 / 1440 px** とします（CSS ブレークポイントの固定値ではなく観測点です）。

### 主な確認パターン

- 作業中・休憩中・未入室・未登録・0 時間・長い作業名・終了予定超過
- 初回読み込み・初回取得失敗・部分障害・更新失敗時の直前成功データ保持
- YouTube ログイン・チャンネル確認・期限切れや競合からのやり直し
- Account メニューの開閉・管理・ログアウト・画像欠落時の代替表示
- Privacy / Terms / Cookie / Contact・利用制限（`403`）・削除処理中
- 直近 7 日のキーボードフォーカス・タップ選択・0 分選択・グラフ外説明・時刻ラベルの収まり

表示単体は開発専用エントリーポイント [visual.tsx](../../../mypage/src/visual.tsx)（本番ビルド非同梱）、認証やルート遷移を含む状態遷移は [runtime.test.ts](../../../mypage/src/runtime.test.ts) で検証します。

```sh
cd mypage
pnpm dev --host 127.0.0.1

# 別シェル（Playwright / Chromium が使える環境）
python -m pip install -r visual-requirements.txt
pnpm test
python scripts/font-qa.py --output /tmp/mypage-font-qa
python scripts/route-focus-qa.py
python scripts/refresh-icon-qa.py --output /tmp/mypage-refresh-icon-qa
```

- QA 時は外部リクエストを遮断し、フォント読み込み完了後に撮影します（実ユーザーデータは保存しません）。合成テストの成功は実 OAuth・Hosting・公開準備完了の根拠にはなりません。
- **`route-focus-qa.py`**: 公開ルート間のキーボード遷移、見出しへのフォーカス移動（同一ルートの検索条件・アンカー変更では移動しない）、Tab 順、戻る・進む、Cookie 設定を閉じた後のフォーカス復帰を検証します。
- **`refresh-icon-qa.py`**: 各幅で更新アイコンの円弧と矢じりの接続、上下対称、17px 正方形、44px 以上の操作領域、横はみ出し、フォーカス、更新中無効化を検証します（Chromium エミュレーションであり物理 iPhone の実測ではありません）。

## bfcache と利用制限の確認

- 旧セッションの遅延応答・復帰時再検証・制限後にデータが復活しないことは、[runtime.test.ts](../../../mypage/src/runtime.test.ts) と [memory.test.ts](../../../mypage/src/features/mypage/memory.test.ts) の代表ケースで検証します。
- 実 Hosting と Chromium 上での bfcache 復帰、利用制限中・削除中の 320 / 390 / 1440px 表示、問い合わせ・再ログイン・ログアウトは [実環境 E2E 手順](../release/e2e.md) で確認します（開発サーバーの HMR を実 bfcache の代わりにはしません）。

## 仕様の優先順位

文言・本人確認・スナップショット時刻・状態・集計は **最新の API 仕様を優先** し、背景・色・影は本ページの「表示の基本原則」に従います。なお、提供されたプロトタイプと付属ランタイムは公開リポジトリへ追加しません。
