## 前提
- Figmaデスクトップアプリがインストールされていること
- ルームレイアウトのワイヤーフレームが作成済みであること
  - 座席が配置され、番号が振られていること

## 使い方
```shell
pnpm install
```

```shell
pnpm dev
```

Figmaデスクトップアプリを開く。

Figmaのメニューから Plugins > Development > Import plugin from manifest を選択し、このディレクトリの `manifest.json` を読み込む。

プラグイン一覧からこのプラグインを選ぶと、プラグインのウィンドウが開く。
