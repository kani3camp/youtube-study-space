## はじめに

コマンドは、`!`から始まります。


## !in

### 入室する

```
!in
```

入室して作業を始めます。

席はランダムに選ばれます。


### 指定した席に座る

`!席番号`と入力すると、指定した席で作業を始められます。

```text title="例：54番席に座る。"
!54
```

### 最も若い番号の席に座る

```
!0
```

空いている席のなかで最も若い番号の席に座って作業を始めます。

### メンバー限定席に座る

```
/in
```

メンバー限定のルームに入室します。
この場合のみ、コマンドは`!`ではなく`/`から始まります。

:::info
[YouTubeメンバー](https://www.youtube.com/channel/UCXuD2XmPTdpVy7zmwbFVZWg/join)のみ、メンバー限定席に座ることができます。
:::

:::warning
`!/in`ではなく、`/in`です。
:::

```text title="例：空いているメンバー限定席のなかで最も若い番号の席に座って作業を始める。"
/0
```

```text title="例：メンバー限定席の3番席に座る。"
/3
```


### 作業名を指定する {#work-option}

`work`オプションを付けると、作業名を指定して作業を始められます。
作業内容（科目など）を自由に指定してください。
全角でも半角でも大丈夫です。

```text title="例：英語を勉強する。"
!in work 英語
```

作業名にはスペースを含められます。

```text title="例：Send Emailという作業名にする。"
!in work Send Email
```


`work `から始まる作業名を使いたいときは、オプション名を省略できません。

```text title="例：work planという作業名にする。"
!in work work plan
```

:::tip
作業名を指定するときは、オプション名（`work`や`w`）を省略できます。

```text title="例：英語を勉強する。"
!in 英語
```

:::

:::info
作業名はつぶやきなどでも OK です。
ただし、画面に映るので不適切な言葉は使わないでください。
:::

### 最大作業時間を指定する {#min-option}

`min`オプションを付けると、最大作業時間（分）を指定して作業を始められます。

指定した時間が経過すると自動で退室します。
作業開始から自動退室するまでの時間（分）を半角数字で指定してください。

```text title="例：30分で自動退室する。"
!in min 30
```

自動退室はあくまでも退室忘れや居座りを防止するための仕組みです。
そのため、基本的には`!out`コマンドで退室してください。
設定可能な値は`5`～`360`の整数です。
デフォルト値は`120`のため、指定しない場合は 120 分で自動退室します。


### メニュー注文を指定する {#order-option}

`order`オプションを付けると、メニューの注文を指定して作業を始められます。

```text title="例：入室と同時にメニューアイテム5を注文する。"
!in order 5
```


:::info

`work`、`min`、`order`の各オプションは同時に使えます。

```text title="例：作業名を「英語」、180分後に自動退室する設定で、メニューアイテム5も注文して入室する。"
!in work 英語 min 180 order 5
```

:::

:::info
`!in`だけでなく、`!席番号`でも`work`、`min`、`order`が使えます。

```text title="例：54番席に座り、作業名を「英語」、180分後に自動退室する設定で、メニューアイテム5も注文する。"
!54 work 英語 min 180 order 5
```

:::

:::warning
`work`オプションはオプション名（`work`）を省略できますが、`min`オプションは`min`を省略できません。

```text title="例：作業名を「英語」にして60分後に自動退室する。"
!in 英語 min 60
```

:::

:::tip
オプション名は短縮できます。`w`は`work`、`m`は`min`、`o`は`order`と同じ意味です。
:::

:::info
`!in`の代わりに、`!work`が使えます。好きなほうを使ってください。
:::



## !out

### 退室する

```
!out
```

退室します。
