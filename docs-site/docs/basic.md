## !info

### 作業履歴を表示する

```
!info
```

累計作業時間と当日の累計作業時間を Bot が教えてくれます。

### 詳細オプション `d`

```
!info d
```

追加で次の情報を確認できます。

-   ランク表示モードのオン／オフ
-   （ランク表示モードがオンの場合）ランクポイント
-   （ランク表示モードがオンの場合）継続日数
-   デフォルト作業時間
-   お気に入りカラー
-   オンライン作業部屋の登録日

## !seat

### 座席の情報を表示する

```
!seat
```

今座っている座席の次の情報をBotが教えてくれます。

-   現在の座席番号
-   入室してからの経過時間
-   入室してからの作業時間（休憩モードの時間を除く）
-   自動退室までの残り時間

### 詳細オプション `d`

```
!seat d
```

追加で、現在の座席に最近どのくらいの時間座ったかを確認できます。

## !change

作業名または入室時間を変更します。
入室中のみ使えるコマンドです。
オプションを 1 つ以上指定する必要があります。

休憩モード中も作業名と休憩時間を変更できます。

### 作業名を変更する

`work`（または`w`）オプションで作業名を変更できます。

```text title="例：作業名を英語に変更する。"
!change work 英語
```

```text title="例：作業名を物理に変更する。"
!change w 物理
```

:::tip
オプション名（`work`や`w`）は省略できます。

```text title="例：作業名を資格試験に変更する。"
!change 資格試験
```

ただし、作業名を消す場合は`work`オプションを省略できません。

```text title="例：作業名を消す。"
!change work
```

作業名を消す場合は、[`!clear`コマンド](#clear)がおすすめです。

:::

:::tip
`!change`の代わりに`!work`も使えます。

```text title="例：作業名を英語に変更する。"
!work 英語
```

:::info
`!work`は`!in`と同じ意味のコマンドです。
:::



### 入室時間を変更する

`min`（または`m`）オプションで入室時間を変更できます。

```text title="例：入室時間を 40 分に変更します。入室してから 10 分経過していた場合、自動退室する時刻は 30 分後（＝入室時刻から 40 分後）に設定されます。"
!change min 40
```

```text title="例：作業名を消して、入室時間を 5 分に変更します。例えば入室から 3 分経過している場合、自動退室時刻は 2 分後（＝入室時刻から 5 分後）に設定されます。"
!change w m 5
```

:::info
すでに指定した時間以上入室している場合、自動退室時刻は変更されません。
:::


## !clear

### 作業名を消す

```text
!clear
```

:::info
`!clear`の短縮形として`!clr`も使えます。

```text
!clr
```
:::


## !more

### 自動退室の時間を延長する

作業時間を延長します。
厳密には、自動退室予定時刻を延長します。
コマンドを実行した時点から最大 360 分後まで、自動退室予定時刻を延長できます。

例えば、コマンドを入力した時点での自動退室予定時刻が 30 分後だった場合、`!more min=30`を実行するとさらに 30 分延長され、60 分後になります。

```text title="例：100分延長する。"
!more 100
```


:::warning
「現在時刻から～分後に自動退室する」のではなく、「自動退室予定時刻を～分延長する」点にご注意ください。
:::

:::tip
オプションを指定しない場合、最大延長時間が適用されます。

```text title="例：最大延長時間を適用する。"
!more
```

:::

:::info
`!more`の代わりに、`!okawari`も同じ意味のコマンドとして使えます。好きなほうを使ってください。
:::


## !order

### メニューを注文する

画面のメニュー表から好きなアイテムを選んで、このコマンドで注文します。
注文したアイテムは、画面上の座席の左上に表示されます。

```text title="例：アイテム3を注文する。"
!order 3
```

:::warning
1日に注文できる回数には上限があります。
:::

:::info
YouTubeメンバーは上限なしで注文できます。
:::

### 注文したアイテムを下げてもらう

座席に表示されたアイテムを消したいときは、番号ではなく`-`（ハイフン）を指定します。

```text
!order -
```
